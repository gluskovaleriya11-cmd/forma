# FORMA LIVING

Статический адаптивный сайт дизайн-студии. Откройте `index.html` в браузере или разместите содержимое папки `outputs` на любом статическом хостинге.

## Возможности

- Главная страница с информацией о студии, работах, услугах, процессе, команде, отзывах и форме консультации.
- Каталог из шести проектов с фильтрами и отдельными страницами проектов.
- Галерея проекта с увеличением изображений, управлением стрелками и клавишей Escape.
- Страницы услуг, интерактивные этапы и мобильная навигация.
- Проверка формы в браузере. Демо-форма ничего не отправляет и не сохраняет.

## Заметки

Интерьерные фотографии созданы специально для концепции сайта и сохранены локально в `assets/`. Шрифты загружаются из Google Fonts; при недоступности сети используются системные запасные шрифты.
